# Algorithms and Data Structures

## Artifact
**CS 360 Weight Tracker Application**

### Overview
This artifact demonstrates my algorithms and data structures skills through enhancements made to a Weight Tracker application originally developed in CS 360. The Android application allows users to record, update, and delete weight entries while storing data in a local SQLite database.

### Enhancements
The project was enhanced by:

- Improving the organization and retrieval of weight data.
- Implementing sorted weight retrieval for more efficient presentation of records.
- Adding weight statistics, including average weight and progress toward a goal.
- Improving database operations used to manage weight entries.
- Maintaining existing add, edit, and delete functionality.
- Testing the enhanced application to verify that all features function correctly.

### Skills Demonstrated
- Java

- Algorithms and Data Structures
- SQLite
- Data Organization and Retrieval
- Sorting and Data Processing
- CRUD Operations
