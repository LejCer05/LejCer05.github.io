# Databases

## Artifact
**CS 340 Animal Shelter Dashboard**

### Overview
This artifact demonstrates my database skills through enhancements made to an Animal Shelter Dashboard originally developed in CS 340. The application uses MongoDB to store, retrieve, and manage animal shelter data while supporting an interactive dashboard for viewing and analyzing records.

### Enhancements
The project was enhanced by:

- Improving MongoDB CRUD operations.
- Strengthening input validation and error handling.
- Improving database queries and filtering.
- Enhancing the organization and retrieval of animal records.
- Improving the reliability and maintainability of database interactions.
- Supporting dashboard functionality through improved database operations.
