# Software Design and Engineering

**CS 320 Contact Service**

### Overview
This artifact demonstrates my software design and engineering skills through enhancements made to a contact management application originally developed in CS 320. The application allows users to create, update, retrieve, and delete contacts while validating user input.

### Enhancements
The project was enhanced by:

- Refactoring duplicated validation logic into reusable helper methods.
- Improving the organization and maintainability of the ContactService class.
- Refining exception handling and validation messages.
- Verifying functionality through automated JUnit testing.

- Java
- Object-Oriented Programming
- Software Design
- Refactoring
- Input Validation
- Exception Handling
- Unit Testing (JUnit)
- Software Maintainability
